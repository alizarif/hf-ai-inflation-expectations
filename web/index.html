Answer quality, noise and cost

Method

How the survey works

Every four hours, at 00, 04, 08, 12, 16 and 20 New York time, each model answers the five inflation questions of the New York Fed Survey of Consumer Expectations. It does so as four different respondents and under five information conditions, three times each.

Design

  1. One shared news search per topic. At the start of each wave, one web search per topic collects ten current articles (title, source, excerpt). Every model in that news arm reads exactly the same text, so differences between models are not differences in what they read.
  2. One message per trial. The system prompt sets the date, time and persona; one user message gives the news (if any) and then all five questions in order. The model answers all five in a single reply, at its default settings.
  3. Parsing without second chances. Answers are read from labelled lines. A probability list that misses 100 is rescaled to 100, with the raw sum kept and the answer flagged; anything unreadable is recorded as invalid. In design v1 (first wave only) a follow-up turn asked again instead.
  4. Everything is kept. Each wave stores the news, every prompt, every raw reply and the parsed answers, and this site is rebuilt from them after every wave.

Reading the results

  • These are the answers of software systems under fixed prompts, not the beliefs of people. Personas are prompt framings, not demographic samples.
  • Within a wave, all trials in an arm share one set of articles. Treat a wave, not a trial, as the unit when judging whether a news effect is real.
  • Trials at default settings show how much a model's answer varies when asked the same thing again.
  • The entertainment arm is a placebo: if it moved expectations as much as economy news, the models would be reacting to any text rather than to information.
  • Distribution means use bin midpoints, with the open-ended bins closed at ±16%. They are descriptive, not the SCE's fitted densities.
